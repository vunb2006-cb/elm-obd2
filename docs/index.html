Before your first scan

Add your Gemini API key

The app uses Google's Gemini API for AI diagnostics. You need your own free API key — it is stored on your phone only and never bundled in the app.

key Setup steps

1

Download the app

Install the APK from GitHub Releases.

2

Get a Gemini API key

Sign in at Google AI Studio, click Create API key, and copy the key (starts with AIza...).

3

Open Settings in the app

On the home screen, tap the gear icon in the top-right corner.

4

Paste and save

Paste your key into the Gemini API Key field and tap Save. Wait for the green Saved confirmation before starting a diagnostic session.

info Without a saved key, the app shows: "No Gemini API key set. Add one in Settings before starting a session."

Hardware

A cheap ELM327 Mini works fine

You do not need an expensive scan tool. This app was tested with a basic Bluetooth ELM327 Mini — the kind sold for around $5 on Amazon, eBay, and auto parts sites worldwide.

  • check_circle Bluetooth Classic (SPP) — not BLE / Bluetooth 4.0-only adapters
  • check_circle Look for ELM327 + Bluetooth icon on the label
  • check_circle Pair the adapter in Android Bluetooth settings before opening the app
  • check_circle Works on OBD-II vehicles (1996+ in the US; similar elsewhere)

No adapter yet? Use Simulate Vehicle in the app to try the full diagnostic flow without hardware.
